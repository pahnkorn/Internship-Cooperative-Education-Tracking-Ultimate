# Internship & Cooperative Education Tracking

ระบบติดตามการฝึกงานและสหกิจศึกษา สำหรับนักศึกษาและพี่เลี้ยง

## ความสามารถของระบบ

- เข้าสู่ระบบ แยกสิทธิ์ตามบทบาท (นักศึกษา / พี่เลี้ยง)
- จัดการข้อมูลนักศึกษา (เพิ่ม แก้ไข ลบ ค้นหา ดูรายละเอียด)
- จัดการสถานประกอบการ
- สมัครฝึกงานและติดตามสถานะ
- ส่งรายงานความคืบหน้ารายสัปดาห์ และความเห็นจากพี่เลี้ยง
- ผลประเมินและหน้าภาพรวมระบบ (Dashboard)

## เทคโนโลยีที่ใช้

| ส่วน | เครื่องมือ |
|---|---|
| ฝั่งเซิร์ฟเวอร์ | Node.js, Express |
| ฐานข้อมูล | MySQL 8.4 (รันใน Docker) |
| ฝั่งหน้าเว็บ | HTML, CSS, JavaScript (ไม่ใช้เฟรมเวิร์ก) |
| ควบคุมเวอร์ชัน | Git, GitHub |

## แพ็กเกจที่ใช้ (npm)

| แพ็กเกจ | ใช้ทำอะไร |
|---|---|
| express | สร้างเว็บเซิร์ฟเวอร์และเส้นทาง API |
| express-session | จำว่าใครล็อกอินอยู่ (session) |
| mysql2 | เชื่อมต่อและสั่งงานฐานข้อมูล MySQL |
| bcryptjs | เข้ารหัสรหัสผ่านก่อนเก็บในฐานข้อมูล |

รายการและเวอร์ชันทั้งหมดอยู่ในไฟล์ package.json
